# Jogoteca Escolar — MVP

- [x] **Loja inicial com catálogo de jogos demonstrativos:** exibir cards com informações essenciais, capa visual, matéria, ano escolar, ação para abrir o jogo no navegador e ação para adicionar à biblioteca.
- [x] **Busca e filtros combináveis:** localizar jogos por título, matéria ou informações relevantes e combinar a busca com filtros por matéria e ano escolar.
- [x] **Biblioteca pessoal:** permitir adicionar e remover jogos da coleção e oferecer acesso rápido para abrir cada jogo salvo.
- [x] **Cadastro manual de jogos:** disponibilizar uma aba com formulário simples para título, link, matéria, ano escolar e dados complementares necessários.
- [x] **Validação e feedback do cadastro:** validar campos obrigatórios e formato de link, mostrar mensagens claras de correção e confirmar o sucesso sem perder os dados digitados.
- [x] **Dados locais e inclusão imediata:** começar com jogos demonstrativos locais e refletir novos cadastros imediatamente na loja, com persistência no navegador.
- [x] **Experiência clara e responsiva:** oferecer navegação por abas entre Loja, Biblioteca e Adicionar jogo, com layout intuitivo para alunos de diferentes idades e sem estética de interface de IA.
